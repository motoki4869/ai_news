# format-report

方針は`~/.agents/docs/skills_policy.md`。このスキルを直す前に読み、失敗が起きたら先にここへケースを足す。

## 合格基準

- 失われた構造（見出し・箇条書き・表）を文面から復元するだけで、要約・加筆・削除をしない。文の意味・語順・数値を変えない。
- 番号の深さに応じて`#`・`##`・`###`にする。「ラベル: 説明」は`- **ラベル**: 説明`にする。連結された表はMarkdownの表に組み直す。
- 同じファイルに上書きし、報告は見出し・表をいくつ組み直したかの1〜2文だけ。全文を貼り直さない。

## テストケース

- 「2.1 技術的特異性: Devinは…」が地の文に埋もれている → `###`の見出しと箇条書きに復元し、文は1字も変えない。
- 「表1: 主要モデル比較 モデル 価格 速度 A 10 速い B 20 遅い」→ 3列の表に組み直す。
- 整形前と整形後で、空白と記号を除いた本文の文字列が一致する。
