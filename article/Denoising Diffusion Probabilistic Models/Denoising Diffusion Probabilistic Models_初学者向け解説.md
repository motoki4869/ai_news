# Denoising Diffusion Probabilistic Models：初学者向け解説

## 1. この論文は何を解決しようとしたのか

この論文は、画像を新しく作る生成AIの学習方法を提案した研究です。後のStable Diffusion、DALL-E 2、Imagenなどの基礎になりました。

生成モデルは、猫の写真を見せて「猫かどうか」を判定するモデルとは違い、学習した画像の特徴を使って、訓練データにない新しい画像を作ります。DDPM（Denoising Diffusion Probabilistic Models）の発想は、画像をいったん完全なノイズにしてから、その逆再生をAIに学習させることです。

## 2. 読む前に知っておきたい用語

| 用語 | 意味 |
|---|---|
| 生成モデル | データの分布を学習し、新しいデータを作るモデル |
| ノイズ | 画像に混ざるランダムな揺らぎ。ここでは主にガウスノイズ |
| 拡散過程 | 元画像に少しずつノイズを加え、ノイズ画像にする固定の手順 |
| 逆拡散過程 | ノイズ画像から少しずつノイズを取り除き、画像を作る手順 |
| タイムステップ `t` | ノイズを何段階目まで加えたかを示す番号 |
| U-Net | 画像の大まかな構造と細部を両方扱いやすいネットワーク |
| FID | 生成画像と本物画像の特徴分布の近さを測る評価指標。低いほどよい |
| Inception score | 生成画像の内容がはっきりしていて、種類も多いかを見る指標 |

## 3. 訓練時に何を学習するのか

### 3.1 正方向：画像を壊す

訓練データの画像を `x_0` とします。そこへ少量のノイズを加えて `x_1`、さらにノイズを加えて `x_2` とし、最終的に `x_T` をほぼランダムなノイズにします。ノイズを加える量は、タイムステップごとのスケジュール `β_1, ..., β_T` で決まります。

この方向は決まった確率過程なので、AIが学ぶ必要はありません。しかも、任意の `t` のノイズ画像を、元画像から一度の計算で作れる式があります。訓練のたびに最初から最後までノイズを足す必要がないため、効率よく学習できます。

### 3.2 逆方向：画像を復元する

生成時は、ランダムなノイズ `x_T` から始めます。ニューラルネットワークに「この画像に含まれるノイズは何か」を予測させ、そのノイズを少しだけ取り除いて `x_{T-1}` を作ります。これを `T` から1まで繰り返すと、画像 `x_0` が得られます。

重要なのは、ネットワークに「きれいな画像そのもの」を直接描かせるのではなく、現在の画像に混ざっているノイズ `ε` を予測させることです。予測ノイズと実際に加えたノイズの平均二乗誤差を小さくするだけなので、学習目標がシンプルで安定しやすくなります。

```text
訓練：画像 → ノイズを加えた画像 → 加えたノイズを当てる
生成：ランダムノイズ → 予測ノイズを除く → 画像
```

### 3.3 なぜU-Netを使うのか

画像生成では、まず「顔らしい輪郭」や「教会らしい配置」のような大まかな構造を決め、後から細かな質感を作る必要があります。U-Netは画像を縮小しながら広い範囲の特徴を見て、拡大しながら細部を戻す構造なので、この処理に向いています。タイムステップの情報はsin/cosの埋め込みでネットワークへ渡します。今どれくらいノイズが残っているかによって、行うべき修正が違うためです。

## 4. 実験結果の読み方

| データセット | 結果 | 読み方 |
|---|---:|---|
| CIFAR-10 | Inception score 9.46 | 画像の内容が明確で多様だった |
| CIFAR-10 | FID 3.17 | 本物画像に近い特徴分布を得た |
| LSUN 256×256 | ProgressiveGANに近い品質 | 高解像度画像でも有効だった |

この結果の意味は、拡散モデルが理論上面白いだけでなく、当時主流だったGANに近い見た目の画像を実際に生成できたことです。さらに、逆拡散の初期段階では画像の大まかな形、後半では細かい質感が作られることも可視化されています。

ただし、FIDやInception scoreは画像全体の傾向を見る指標で、人間の好みや事実性を完全に測るものではありません。

## 5. 限界と現在の画像生成AIとの違い

- 多くのタイムステップを順番に処理するため、GANなどより生成に時間がかかる。
- 元論文の主な実験は無条件生成で、文章から画像を作る仕組みは後続研究で追加された。
- 学習データの偏りや、実在人物・作品に似た画像を生成する問題は残る。
- 「ノイズを除けば必ず元画像を復元できる」という意味ではなく、学習した分布に合う新しい画像を確率的に作る。

次に学ぶなら、VAEとGANの違い、スコア関数、Classifier-Free Guidance、潜在空間で拡散するLatent Diffusionの順がおすすめです。

## 6. まとめ

DDPMは、画像にノイズを加えて壊す手順の逆向きを学習し、ランダムノイズから少しずつ画像を作るという、現在の画像生成AIの基本原理を確立しました。
