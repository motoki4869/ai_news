# Attention Is All You Need：初学者向け解説

## 1. この論文は何を解決しようとしたのか

この論文は、英語をドイツ語やフランス語へ翻訳するような「文章から別の文章を作る」AIの構造を提案した研究です。2017年の論文ですが、後のBERT、GPT、T5、そしてChatGPTなどの大規模言語モデルの基本設計になりました。

当時の主流はRNN（再帰ニューラルネットワーク）でした。RNNは単語を左から右へ順番に処理するため、長い文章では計算を並列化しにくく、離れた単語同士の関係も学習しにくいという問題がありました。そこで著者らは、順番に処理する仕組みを使わず、文章中の単語同士の関係をAttentionで直接計算するTransformerを提案しました。

## 2. 読む前に知っておきたい用語

| 用語 | 意味 |
|---|---|
| トークン | AIが処理する単語や単語の一部 |
| 埋め込み | トークンの意味や特徴を表す数値ベクトル |
| エンコーダ | 入力文を、文脈を含む内部表現に変換する部分 |
| デコーダ | 内部表現を見ながら出力文を1トークンずつ作る部分 |
| Self-Attention | 文中の各トークンが、同じ文のどのトークンをどれだけ参照するか計算する仕組み |
| Query / Key / Value | 「何を探すか」「何と照合するか」「取り出す情報」を表す3種類のベクトル |
| 並列化 | 複数の計算を同時に実行すること。GPUが得意 |
| 自己回帰生成 | すでに生成した内容を使って、次のトークンを順番に出すこと |

## 3. Transformerの入力から出力まで

例えば、英語の文をフランス語に翻訳するとします。

1. 入力文をトークンに分け、各トークンを埋め込みベクトルに変換する。
2. 位置エンコーディングを加える。Transformerは単語を同時に処理するため、単語の順番を別途教える必要がある。
3. エンコーダのSelf-Attentionで、各単語が文中の他の単語を参照しながら文脈を作る。
4. デコーダが、エンコーダの出力と、それまでに生成したフランス語を使って次の単語を予測する。
5. 文末を表すトークンが出るまで生成を繰り返す。

### Self-Attentionは何を計算しているのか

ある単語の表現を更新するとき、まずその単語からQueryを作ります。文中の各単語からKeyとValueを作り、QueryとKeyの内積で「どの単語が関係ありそうか」を計算します。関係が強い単語のValueには大きな重みを付け、重み付き平均を新しい表現にします。

論文の式は次の形です。

```text
Attention(Q, K, V) = softmax(QK^T / √d_k)V
```

ここで、`QK^T`はQueryとKeyの相性、`softmax`は相性の数値を合計1の重みに変換する処理、`V`は実際に集める情報です。`√d_k`で割るのは、ベクトルの次元が大きいと内積が大きくなりすぎて学習しにくくなるのを防ぐためです。

### なぜMulti-Headなのか

Attentionを1種類だけ使うのではなく、8個のヘッドに分けて別々に計算します。あるヘッドは代名詞とその指す名詞、別のヘッドは動詞と目的語、さらに別のヘッドは文の構造を見る、といった役割分担を学べます。最後に各ヘッドの結果を結合します。

### エンコーダとデコーダの違い

エンコーダは入力文全体を見てよいので、文の前後を含む情報を使えます。デコーダは未来の正解を先に見てはいけないため、マスクを使って、現在より後ろの出力を参照できないようにします。これが、学習時に答えを盗み見ず、実際の生成と同じ条件で予測するための仕組みです。

## 4. 実験結果の読み方

| タスク | Transformerの結果 | 何を意味するか |
|---|---:|---|
| WMT2014 英独翻訳 | BLEU 28.4 | 従来の最良結果を2 BLEU以上更新 |
| WMT2014 英仏翻訳 | BLEU 41.8 | 8基のGPUで3.5日学習した単一モデルとして当時最高 |
| 英語構文解析 | F1 91.3（WSJのみ） | 翻訳以外の言語タスクにも応用できた |

BLEUは翻訳文と正解訳の語句の一致度を基にした指標で、一般に高いほどよい結果です。ただし、BLEUが高いからといって、人間にとって常に自然な翻訳とは限りません。重要なのは、Transformerが品質だけでなく、RNNより並列化しやすく、訓練時間も短かったことです。

## 5. この論文の限界と、その後の発展

- Self-Attentionは、文中のすべてのトークンの組み合わせを調べるため、系列が長くなると計算量とメモリが二次的に増える。
- デコーダの文章生成は、次のトークンを順番に決める必要があり、推論時の完全な並列化はできない。
- 2017年のTransformerは翻訳モデルであり、現在のChatGPTのような会話性能をそのまま持っていたわけではない。大規模事前学習、指示調整、人間のフィードバックなどが後から加わった。

次に学ぶなら、RNN・LSTMとの比較、Attentionの行列計算、BERTの双方向エンコーダ、GPTのデコーダ専用構造の順が分かりやすいです。

## 6. まとめ

Transformerは、単語を1つずつ順番に処理する代わりに、文中の単語同士の関係をSelf-Attentionで同時に計算し、品質と学習効率を両立したモデルです。
