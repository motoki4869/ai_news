# Sequence to Sequence Learning with Neural Networks：初学者向け解説

## 1. この論文は何を解決しようとしたのか

この論文は、英語の文をフランス語の文へ翻訳するような「長さの違う系列を、別の系列へ変換する」問題に、ニューラルネットワークだけで取り組んだ研究です。2014年に発表され、現在のEncoder-Decoder型モデルやTransformerへつながる重要な出発点になりました。

当時の一般的なニューラルネットワークは、入力と出力のサイズが決まっている問題を得意としていました。しかし、英語10単語の文がフランス語15単語になるように、入力と出力の長さが変わる翻訳には、そのままでは使いにくいという課題がありました。

## 2. 読む前に知っておきたい用語

| 用語 | 意味 |
|---|---|
| 系列（sequence） | 順番を持つデータ。文章や音声など |
| LSTM | 過去の情報を保持・更新する仕組みを持つRNN |
| 隠れ状態 | それまでに読んだ情報を表す内部ベクトル |
| エンコーダ | 入力系列を読み、意味を表すベクトルへ変換する部分 |
| デコーダ | ベクトルと過去の出力を使って、出力系列を生成する部分 |
| `<EOS>` | 出力が終わったことを表す特殊トークン |
| 尤度 | モデルが、その出力をどれくらい自然だと評価しているか |
| ビームサーチ | 複数の候補を残しながら、確率の高い出力を探す方法 |

## 3. エンコーダ・デコーダの処理の流れ

例えば `I love cats` をフランス語に翻訳するとします。

1. エンコーダLSTMが入力を1単語ずつ読み、最後の隠れ状態を作る。
2. 最後の隠れ状態を、入力文全体の意味を圧縮したベクトル `v` とみなす。
3. デコーダLSTMが `v` を初期状態として、最初のフランス語単語を予測する。
4. 予測した単語を次の入力として、次の単語を予測する。
5. `<EOS>` が出るまで繰り返す。

数式では、出力文の確率を次のように分解します。

```text
p(y1, ..., yT' | x1, ..., xT)
= p(y1 | v) × p(y2 | v, y1) × ... × p(yT' | v, y1, ..., yT'-1)
```

つまり、翻訳全体を一度に当てるのではなく、「ここまでの入力と、ここまでに出した訳から、次の単語は何か」を順番に予測します。

### LSTMが必要な理由

普通のRNNは長い文を読むと、最初の方の情報が薄れやすい問題があります。LSTMは、情報を残すか捨てるかをゲートで調整し、長い距離の依存関係を扱いやすくします。ただし、入力文全体を1つのベクトルへ圧縮するため、非常に長い文では情報が詰め込まれすぎるボトルネックが残ります。この問題が、後のAttentionの登場理由の一つになります。

## 4. この論文の重要な工夫

### 入力文を逆順にする

入力をそのまま `a, b, c` の順に読むのではなく、`c, b, a` と逆から読みます。出力の最初の単語と、入力の最後に近い単語が処理上近くなるため、入力と出力の対応関係を学習しやすくなります。

これは意味を変える工夫ではありません。単語同士の対応を学習するまでの「時間的な距離」を短くする、最適化上の工夫です。実際に、反転なしの単一モデルではBLEU 25.9、反転ありではBLEU 30.6まで改善しました。

### ビームサーチ

生成時に最も確率の高い単語を毎回1つだけ選ぶと、早い段階の小さな選択ミスで全体が悪くなることがあります。ビームサーチでは、例えば上位12個の部分的な翻訳を残し、それぞれを伸ばしながら最終的に確率の高い候補を選びます。

## 5. 実験結果の読み方

WMT'14英仏翻訳で、5個の反転LSTMを組み合わせたモデルはBLEU **34.81**を達成しました。統計的機械翻訳のベースラインは33.30だったため、ニューラルネットワークだけの方式が大規模な翻訳タスクで初めてベースラインを上回った結果です。

さらに、SMTが作った候補1000個をLSTMで再評価するとBLEU 36.5まで上がりました。つまり、この研究のモデルは完全な置き換えだけでなく、既存方式の候補をよりよく選ぶ部品としても役立ちました。

長い文で性能が大きく崩れなかったこと、学習した文ベクトルが単語の順序や意味の違いをある程度表現できたことも重要です。

## 6. 限界と、その後の発展

- 文全体を1つの固定長ベクトルに圧縮するため、長文では情報が失われる可能性がある。
- LSTMは単語を順番に読むので、学習を大きく並列化しにくい。
- 出力生成も1単語ずつ行うため、推論は逐次的になる。

このボトルネックを補うために、BahdanauらのAttentionが入力の各位置を直接参照できるようにし、2017年のTransformerはRNNを使わずAttention中心の構造へ進みました。

## 7. まとめ

Seq2Seqは、入力文をエンコーダで意味ベクトルにまとめ、デコーダで別の長さの文へ展開する設計を示し、ニューラル機械翻訳の基礎を作りました。
